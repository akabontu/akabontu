💡 Cara Kerja:

  • Data Source: Tabel itc_pn dari database adpaneldb
  • Wrapper height: 520px (container utama)
  • Thead: display: table dengan position sticky
  • Tbody: display: block dengan overflow-y: scroll, height: 460px
  • Tbody tr: display: table dengan table-layout: fixed (agar lebar kolom sama dengan header)
  • Width kolom: Harus didefinisikan sama di th dan td agar sejajar

⚠️ Catatan Penting:

  • Setiap kolom harus punya width yang spesifik dan sama di thead th dan tbody td
  • Total width semua kolom sebaiknya sedikit lebih besar dari wrapper untuk menghindari jumping
  • Gunakan table-layout: fixed untuk konsistensi lebar kolom
  • Scrollbar akan muncul di tbody, bukan di wrapper luar
  • Data diambil langsung dari tabel itc_pn dengan query ORDER BY no DESC
