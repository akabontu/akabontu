# Checklist Persetujuan Desain

Panduan singkat: checklist ini dipakai untuk menandai item yang harus disetujui sebelum lanjut ke implementasi.

- [ ] Visual: skema warna, tipografi, ikon, spacing.
- [ ] Komponen UI: tombol, form, kartu produk — semua varian cek.
- [ ] Responsivitas: tampilan di mobile, tablet, desktop (breakpoints utama).
- [ ] Konten: copy final tersedia dan akurat.
- [ ] Gambar & aset: resolusi dan lisensi terverifikasi.
- [ ] Aksesibilitas: fokus keyboard, label form, teks alternatif gambar.
- [ ] SEO dasar: judul halaman, meta description, struktur heading.
- [ ] Performa: ukuran bundle estimasi, lazy-load untuk media.
- [ ] Integrasi Backend: daftar API yang perlu tersedia sebelum fitur aktif.
- [ ] Keamanan: pertimbangan auth, rate-limit, sanitasi input.
- [ ] Rencana deploy: staging, rollback, dan jadwal go-live.
